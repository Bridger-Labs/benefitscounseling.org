# Changes in this prototype

## November 2026 — BenefitsCounseling.org tool platform

- Redesigned the original single SMART Goals worksheet into a responsive navigation-based benefits planning toolkit.
- Added the SSI income and federal payment calculator, with an explicit calculation trail.
- Added TWP/EPE month history tracker with 2017–2027 rate history and CSV export.
- Added editable work scenario comparisons with conditional SSDI guidance.
- Added a dynamically assembled benefits summary and browser print-to-PDF / text export.
- Added conditional review sections for Medicaid, Medicare, SNAP, and housing benefits in the report.
- Added a rule reference center citing SSA primary sources, 2026–2027 federal rates, and calculation limitations.
- Retained the existing SMART goals worksheet route.
- Added Vercel SPA rewrite configuration and deployment documentation.
- Removed the old GitHub Pages workflow to avoid competing deploy paths.
- Added core rule-engine unit tests.

No backend, account, or database is required. Rules require independent CPWIC/SSA review before use in individual counseling or public launch.
